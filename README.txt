# Money Calculator Pro — iPhone Web App

This is an installable Progressive Web App (PWA), not a native App Store app.

## Put it on your iPhone
1. Upload the contents of this folder to an HTTPS host (for example, a GitHub Pages site).
2. Open the resulting HTTPS website in Safari on your iPhone.
3. Tap Share → Add to Home Screen → Add.
4. Open it from the new Home Screen icon. It can cache its files for offline use after the first load.

## Features
- Live balance entry and quick balance buttons
- NPSB, bKash to Bank, Cash Out example rates
- Maximum send and custom transfer amount modes
- Optional balance reserve
- Custom fee rate and copyable summary

## Important
Rates are user-provided example values, not verified current provider fees. Check actual fee/VAT/rounding and transaction limits in the provider app before transferring money.
